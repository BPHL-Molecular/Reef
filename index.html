Two ways to see how a pathogen moves.

A genome carries two readable traces of an outbreak: a lineage you can draw as a tree, and a web of close genetic matches you can draw as a network. Reef renders both — Loggerhead for the tree, Calusa for the network — in your browser, from your own sequence data.

Plate I · Phylogeny

Loggerhead

An interactive viewer for time-resolved phylogenetic trees.

Reads
Auspice / Nextstrain JSON or Newick (.nwk, .tree, .tre)
Shows
Tree layouts, clade & geography coloring, divergence vs. date
Answers
How are these genomes related, and when did they diverge?
Open Loggerhead Source

Named for the loggerhead sea turtle, which nests along Florida’s coasts.

Plate II · Network

Calusa

An interactive viewer for genetic-distance transmission networks.

Reads
FASTA haplotypes → network JSON
Shows
Force-directed graph, distance-threshold clusters, link weighting
Answers
Which samples are close enough to be linked?
Open Calusa Source

Named for Calusa Beach on Bahia Honda Key, Florida.

Data handlingLocal only

Your sequences never leave the browser.

Both tools read the file you open on your own machine and render it there. Nothing is uploaded — not to GitHub, not to us, not to any server. Save either page and it runs fully offline. That matters when genomic data is tied to identifiable, reportable conditions and cannot be sent to an outside service.
